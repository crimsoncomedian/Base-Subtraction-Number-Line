# Number Line: Subtraction Facts in Other Bases

A quick practice interactive using the measurement model. Each problem is a subtraction fact in a base from 2 to 9, such as 12 - 4 in base 5. Students type the answer in that base, or tap Show me to watch the hops on a number line labelled in that base: start at the first number, hop left once for each unit of the second number, and the landing spot is circled. Then a new problem appears.

Open `index.html` in a browser, no build step needed.
